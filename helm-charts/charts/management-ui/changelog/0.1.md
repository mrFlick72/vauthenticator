# management-ui helm chart 0.1

## :star: New Features

- initial release of the `management-ui` chart: Deployment + ClusterIP Service for the `management-ui` static React SPA served by nginx, configured through `application.configManagerUpstream`
- add an optional Ingress (`ingress.*`, enabled by default) for external access
- add an optional Gateway API `Gateway` + `HTTPRoute` (`gateway.enabled` / `httpRoute.*`, both disabled by default) as an alternative to the Ingress, mirroring the pattern used by the `vauthenticator` chart's `application` workload; `ingress.enabled` and `httpRoute.enabled` are mutually exclusive
