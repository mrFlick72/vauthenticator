# management-ui helm chart 0.1

## :star: New Features

- initial release of the `management-ui` chart: Deployment + ClusterIP Service for the `management-ui` static React SPA served by nginx, configured through `application.configManagerUpstream`
- add an optional Ingress (`ingress.*`, enabled by default) and an optional Gateway API `HTTPRoute` (`gateway.*`, disabled by default) for external access, mirroring the pattern used by the `config-manager` chart
