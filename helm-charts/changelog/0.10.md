# VAuthenticator helm charts 0.10

## :boom: Breaking Changes

- DynamoDB support removed, PostgreSQL is the only persistence [#402](https://github.com/mrFlick72/vauthenticator/issues/402)
  - `application.datasource.url` is always required; rendering fails without it
  - `application.profiles` defaults to `kms`; drop `dynamo` and `database` from existing values
  - `application.dynamoDb.*` and `application.aws.dynamodb.endpointOverride` are removed
  - `application.dynamoDb.role.protectedFromDelete` moves to `application.role.protectedFromDelete`
  - the account, role and client application caches move to `application.cache.{account,role,clientApplication}.{enabled,ttl,name}`, off by default
  - there is no migration from DynamoDB: redeploy on PostgreSQL
