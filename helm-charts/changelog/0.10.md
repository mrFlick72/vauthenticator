# VAuthenticator helm charts 0.10

## :star: New Features

- ticket lifetimes per purpose, as `application.ticket.ttl.mfaEnrollment` (`5m`), `application.ticket.ttl.resetPassword` (`15m`) and `application.ticket.ttl.emailVerification` (`24h`) [#339](https://github.com/mrFlick72/vauthenticator/issues/339)
- Failed-Login Lock settings, as `application.login.failedLoginLock.threshold` (`5`) and `application.login.failedLoginLock.duration` (`1m`) [#434](https://github.com/mrFlick72/vauthenticator/issues/434)

## :art: Refactoring

- `application.assetServer.onS3.enabled` removed: auth-server never read it [#434](https://github.com/mrFlick72/vauthenticator/issues/434)

## :warning: Upgrade notes

- `files/schema.sql` adds the `PASSWORD_LIFECYCLE_RULES` table (password lifecycle [#298](https://github.com/mrFlick72/vauthenticator/issues/298)) and the `ACCOUNT.locked_until` column (Failed-Login Lock [#211](https://github.com/mrFlick72/vauthenticator/issues/211)). An existing database needs, before upgrading:

  ```sql
  CREATE TABLE PASSWORD_LIFECYCLE_RULES
  (
      user_name                   varchar(255) not null,
      evaluation_interval_seconds bigint       not null,
      created_at                  TIMESTAMP    not null,
      last_evaluation_date        TIMESTAMP,
      action                      varchar(255) not null,
      primary key (user_name, action)
  );
  ALTER TABLE ACCOUNT ADD COLUMN locked_until TIMESTAMP WITH TIME ZONE;
  ```

  [#434](https://github.com/mrFlick72/vauthenticator/issues/434)

- `files/schema.sql` adds `TICKET.code_attempts`, the count of MFA association codes checked against a ticket. The schema only runs on a fresh database, so an existing one needs, before upgrading:

  ```sql
  ALTER TABLE TICKET ADD COLUMN code_attempts integer NOT NULL DEFAULT 0;
  ```

  Without it every association code fails with a server error. [#339](https://github.com/mrFlick72/vauthenticator/issues/339)
- Tickets issued before the upgrade: MFA enrollments in progress must be started again and email-verification links must be requested again, because those tickets carry no purpose; reset-password links keep working only until 5 minutes after they were sent, the lifetime they were issued with. [#339](https://github.com/mrFlick72/vauthenticator/issues/339)
