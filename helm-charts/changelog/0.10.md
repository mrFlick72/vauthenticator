# VAuthenticator helm charts 0.10

## :star: New Features

- ticket lifetimes per purpose, as `application.ticket.ttl.mfaEnrollment` (`5m`), `application.ticket.ttl.resetPassword` (`15m`) and `application.ticket.ttl.emailVerification` (`24h`) [#339](https://github.com/mrFlick72/vauthenticator/issues/339)

## :warning: Upgrade notes

- `files/schema.sql` adds `TICKET.code_attempts`, the count of MFA association codes checked against a ticket. The schema only runs on a fresh database, so an existing one needs, before upgrading:

  ```sql
  ALTER TABLE TICKET ADD COLUMN code_attempts integer NOT NULL DEFAULT 0;
  ```

  Without it every association code fails with a server error. [#339](https://github.com/mrFlick72/vauthenticator/issues/339)
